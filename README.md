Menu de Produtos em C#

Projeto desenvolvido durante meus estudos de Engenharia de Software para praticar conceitos fundamentais de lógica de programação utilizando C#.

 Sobre o projeto

O programa apresenta um menu com seis produtos. O usuário deve escolher uma das opções disponíveis e, de acordo com sua escolha, o programa exibe:

- Nome do produto
- Valor unitário
- Quantidade disponível em estoque

Caso seja escolhida uma opção que não esteja disponível no menu, o programa informa que a opção é inválida.

 Conceitos praticados

Neste projeto, pratiquei:

- Variáveis
- Entrada de dados com `Console.ReadLine()`
- Conversão de dados com `int.Parse()`
- Estrutura `switch/case`
- Estrutura `default`
- Estruturas de decisão
- Lógica de programação

 Tecnologias utilizadas

- C#
- .NET
- Visual Studio Code

 Objetivo

Praticar os fundamentos da programação em C# e desenvolver minha capacidade de resolver problemas utilizando estruturas de decisão e lógica de programação.

 Contexto

Este é um dos meus primeiros projetos desenvolvidos durante a graduação em Engenharia de Software. O projeto faz parte da minha prática de programação e representa uma etapa inicial da minha jornada no desenvolvimento de software.
